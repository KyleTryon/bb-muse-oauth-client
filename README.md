# Muse.ai BB OAuth client

Public OAuth client metadata for a Muse.ai connection to BB.

Client ID: https://kyletryon.github.io/bb-muse-oauth-client/client.json

Uses authorization code with PKCE S256, scope `bb`, and no client secret. This document contains no credentials and grants no access by itself. BB access requires the owner to approve an OAuth sign-in.

The sole permitted callback is `https://agent.meta.ai/api/hatch/oauth/callback`. Keep this repository published through GitHub Pages while using the connection.
